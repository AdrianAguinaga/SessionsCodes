<h2 style="color: #0d2c4f; border-bottom: 3px solid #d23939; padding-bottom: 6px; font-size: 1.35rem;">🎯 Learning Outcomes</h2>
<div style="background-color: #ffffff; border-radius: 10px; padding: 20px 22px; margin-bottom: 24px; border: 1px solid #dde5ec;">
    <h3 style="color: #0d2c4f; margin-top: 0;">📖 Introduction</h3>
    <p style="color: #1f2d3d; line-height: 1.6;">In React, managing the flow of data between our components is essential for building interactive and maintainable user interfaces. The most fundamental pattern is passing data from parent to child components using <strong>props</strong>. Our React components are simply functions that receive a single parameter called <code>props</code>, which is an object containing any data or functions the parent wants to provide.</p>
    <h4 style="color: #1b5a8a; margin-top: 24px; margin-bottom: 12px;">⬇️ From Parent to Child with Props</h4>
    <p style="color: #1f2d3d; line-height: 1.6;">The simplest and most common direction for data flow in React is <strong>downwards</strong>&mdash;from parent to child. When a parent component wants to supply data to a child, it passes the data as attributes in the JSX tag that renders the child.</p>
    <p style="color: #1f2d3d; line-height: 1.6;">For example, consider a <code>BookList</code> component that manages an array of book objects. As it renders a list of <code>Book</code> components, it passes each book's details (such as title and author) as props. This allows each child to receive and display its own unique data without needing to know about the entire list.</p>
    <pre style="background-color: #0d2c4f; color: #e8f0f8; border-radius: 8px; padding: 16px; margin: 16px 0; overflow-x: auto; font-family: monospace; font-size: 0.95rem;"><code>function BookList({ books }) {
  return (
    &lt;div&gt;
      {books.map(book =&gt; (
        &lt;Book key={book.id} title={book.title} author={book.author} /&gt;
      ))}
    &lt;/div&gt;
  );
}</code></pre>
    <p style="color: #5a6b7c; font-size: 0.95rem; margin-top: 8px; margin-bottom: 24px;"><em>Here, <code>title</code> and <code>author</code> are props passed from the parent (<code>BookList</code>) to the child (<code>Book</code>).</em></p>
    <h4 style="color: #1b5a8a; margin-top: 24px; margin-bottom: 12px;">⬆️ From Child to Parent with Callbacks</h4>
    <p style="color: #1f2d3d; line-height: 1.6;">Sometimes, we need to communicate <strong>upwards</strong>&mdash;from a child to its parent. Since data can't flow directly from child to parent in React, the parent must provide a <strong>callback function</strong> as a prop to the child. The child can then invoke this function when a specific event occurs (such as an input change) to inform the parent of a state change or user action.</p>
    <p style="color: #1f2d3d; line-height: 1.6;">For example, a <code>QuantityPicker</code> child component might receive an <code>onQuantityChange</code> function prop from its parent. When the user selects a new quantity, the child calls this function, passing the new value back up to the parent, which can then update its state accordingly.</p>
    <pre style="background-color: #0d2c4f; color: #e8f0f8; border-radius: 8px; padding: 16px; margin: 16px 0; overflow-x: auto; font-family: monospace; font-size: 0.95rem;"><code>function QuantityPicker({ onQuantityChange }) {
  return (
    &lt;input
      type="number"
      onChange={e =&gt; onQuantityChange(Number(e.target.value))}
    /&gt;
  );
}</code></pre>
    <p style="color: #5a6b7c; font-size: 0.95rem; margin-top: 8px; margin-bottom: 0;"><em>This pattern enables two-way communication: parents provide data and functions to children, and children notify parents of changes or actions.</em></p>

        <h3 style="color: #d23939; margin-top: 0;">💡 Discussion &amp; Reflection</h3>
        <ul style="color: #1f2d3d; padding-left: 20px; margin-bottom: 0;">
            <li style="margin-bottom: 12px;"><strong>How does a component inform its parent about a state change?</strong><br /><span style="color: #5a6b7c;">It informs its parent by calling a <strong>callback function</strong> that was passed down from the parent as a prop. This allows the parent to update its own state in response to child events.</span></li>
            <li style="margin-bottom: 12px;"><strong>Why is <code>useState</code> local to each Product?</strong><br /><span style="color: #5a6b7c;">The <code>useState</code> hook is local to each <code>Product</code> component instance. This means each product maintains its own independent state (like selected quantity), ensuring changes in one product don't affect others.</span></li>
            <li><strong>How can this system scale to a full cart?</strong><br /><span style="color: #5a6b7c;">We can scale this by having each product communicate quantity changes up to a parent Cart component via callbacks. The parent aggregates this data, computes totals, and manages the overall state of the cart.</span></li>
        </ul>
