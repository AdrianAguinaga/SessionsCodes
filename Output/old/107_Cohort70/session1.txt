<div style="background-color: #ffffff; border-radius: 10px; padding: 20px 22px; margin-bottom: 24px; border: 1px solid #dde5ec;">
    <h3 style="color: #0d2c4f; margin-top: 0;">📖 Introduction</h3>
    <p style="color: #1f2d3d; line-height: 1.6;"><strong>React</strong> is a declarative, efficient, and flexible <strong>JavaScript library</strong> designed specifically for building user interfaces. It empowers us to create complex and interactive UIs by breaking them down into small, independent, and reusable pieces of code known as <strong>components</strong>. Each component encapsulates its own structure, style, and behavior, and can manage its own <strong>state</strong> and <strong>logic</strong>.</p>
    <p style="color: #1f2d3d; line-height: 1.6;">At the core of React is its <strong>component-based architecture</strong>. This not only promotes reusability but also simplifies the management of large applications by allowing us to focus on smaller, manageable pieces of the UI at a time.</p>
    <p style="color: #1f2d3d; line-height: 1.6;">React also utilizes a <strong>virtual DOM</strong>&mdash;a lightweight copy of the actual DOM&mdash;which enables it to efficiently update only the parts of the UI that have changed. This selective updating results in faster rendering and improved overall performance.</p>
    <p style="color: #1f2d3d; line-height: 1.6;">Its <strong>declarative programming style</strong> means instead of specifying how to change the UI step-by-step, we describe what the UI should look like for any given state. React takes care of updating the DOM accordingly, making our code more predictable and simpler to debug. Additionally, React uses <strong>JSX</strong>&mdash;a syntax extension that lets us write HTML-like code inside JavaScript.</p>
</div>
