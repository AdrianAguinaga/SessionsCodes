    <div style="flex: 1 1 280px; background-color: #f7fafc; border-left: 4px solid #d23939; border-radius: 0 8px 8px 0; padding: 12px 16px; color: #1f2d3d;">✅ Give DOM elements an <strong>identity</strong> by binding the server-generated ID to the HTML.</div>

    <div style="flex: 1 1 280px; background-color: #f7fafc; border-left: 4px solid #d23939; border-radius: 0 8px 8px 0; padding: 12px 16px; color: #1f2d3d;">✅ Describe the complete <strong>CRUD cycle</strong> of your full stack application.</div>
</div>
<div style="background-color: #fdf3f3; border-radius: 10px; padding: 16px 22px; margin-bottom: 28px; border: 1px solid #f0c9c9;">
    <p style="margin: 0 0 8px 0; color: #0d2c4f;"><strong>💡 Key Concept &mdash; Why does <code>$(".btn-delete").click(...)</code> fail?</strong></p>
    <p style="margin: 0; color: #1f2d3d; font-size: 0.95rem;">Because when <code>init()</code> runs, those delete buttons <strong>don't exist yet</strong> &mdash; they're created later when data loads from the server. The solution is <strong>Event Delegation</strong>: attach the listener to a parent that always exists (<code>.list</code>) and let the click "bubble up" to it.</p>
</div>
<h2 style="color: #0d2c4f; border-bottom: 3px solid #d23939; padding-bottom: 6px; font-size: 1.35rem;">📚 What We'll Build Today</h2>
<p style="color: #1f2d3d; margin-bottom: 16px;">Today we complete the <strong>CRUD cycle</strong> of the Task Manager and make the interface truly interactive. Click each part to expand the details.</p>
<details style="background-color: #ffffff; border-radius: 10px; padding: 14px 18px; margin-bottom: 10px; border: 1px solid #dde5ec;">
    <summary style="cursor: pointer; color: #0d2c4f; font-size: 1.05rem;"><strong>Part 1 &middot; The "Identity" Problem</strong> &mdash; Binding the server ID to the DOM</summary>
    <p style="margin: 12px 0 6px 0; color: #1f2d3d;">To delete a specific task, the DOM element must know <em>which</em> task it represents. We update <code>displayTask()</code> to add <code>id="${task.id}"</code> (the ID generated by the server in Session 3) to the parent <code>&lt;div&gt;</code>, plus a <code>&lt;button class="btn-delete"&gt;🗑️&lt;/button&gt;</code> on every card.</p>
</details>
<details style="background-color: #ffffff; border-radius: 10px; padding: 14px 18px; margin-bottom: 10px; border: 1px solid #dde5ec;">
    <summary style="cursor: pointer; color: #0d2c4f; font-size: 1.05rem;"><strong>Part 2 &middot; Event Delegation</strong> &mdash; Catching clicks "higher up" the tree</summary>
    <p style="margin: 12px 0 6px 0; color: #1f2d3d;">When a user clicks the trash icon on a <em>new</em> task, the click <strong>bubbles up</strong> the DOM tree until something catches it:</p>
    <pre style="background-color: #0d2c4f; color: #e8f0f8; border-radius: 8px; padding: 16px; font-size: 0.85rem; overflow-x: auto;">📡 EVENT DELEGATION VISUALIZED

 1. [ Trash Icon ]  ◄── CLICK!
      │                "Do I have a listener?" NO.
      ▼ (Bubbles Up)

 2. [ Task Div ]    ◄── "Do I have a listener?" NO.
      │
      ▼ (Bubbles Up)

 3. [ #list Div ]   ◄── "Do I have a listener?" YES!
      │                We attached: $(".list").on("click", ...)
      │
      └── Logic: "Was the actual target a '.btn-delete'?
          YES &rarr; Execute deleteTask()"</pre>
    <p style="margin: 12px 0 6px 0; color: #1f2d3d;">In code, we replace the old direct binding with the delegated version:</p>
    <pre style="background-color: #0d2c4f; color: #e8f0f8; border-radius: 8px; padding: 16px; font-size: 0.85rem; overflow-x: auto;">// OLD WAY (doesn't work for dynamic items):
// $(".btn-delete").click(deleteTask);

// NEW WAY (Event Delegation):
$(".list").on("click", ".btn-delete", deleteTask);</pre>
</details>
<details style="background-color: #ffffff; border-radius: 10px; padding: 14px 18px; margin-bottom: 10px; border: 1px solid #dde5ec;">
    <summary style="cursor: pointer; color: #0d2c4f; font-size: 1.05rem;"><strong>Part 3 &middot; AJAX DELETE</strong> &mdash; Remove from server, then from screen</summary>
    <p style="margin: 12px 0 6px 0; color: #1f2d3d;">Inside <code>deleteTask()</code>, four moves happen before the request:</p>
    <ul style="color: #1f2d3d; margin: 6px 0;">
        <li style="margin-bottom: 4px;"><strong>Context:</strong> <code>this</code> is the specific button that was clicked.</li>
        <li style="margin-bottom: 4px;"><strong>Traversal:</strong> <code>.parents(".task")</code> climbs up to the task card.</li>
        <li style="margin-bottom: 4px;"><strong>Extraction:</strong> <code>.attr("id")</code> reads the unique ID we stored in the HTML.</li>
        <li><strong>Communication:</strong> <code>type: "DELETE"</code> to <code>API + "/" + id</code>; on success, <code>fadeOut(500)</code> then <code>.remove()</code> from the DOM tree.</li>
    </ul>
    <p style="margin: 12px 0 6px 0; color: #1f2d3d;"><strong>Server side:</strong> the backend simply filters the array &mdash; <code>DB = DB.filter(t =&gt; t.id !== id)</code>.</p>
</details>
<details style="background-color: #ffffff; border-radius: 10px; padding: 14px 18px; margin-bottom: 28px; border: 1px solid #dde5ec;">
    <summary style="cursor: pointer; color: #0d2c4f; font-size: 1.05rem;"><strong>Part 4 &middot; Client-Side Filtering</strong> &mdash; Logic that never touches the server</summary>
    <p style="margin: 12px 0 6px 0; color: #1f2d3d;">We add <strong>All / Completed / Pending</strong> filter buttons above the list. The <code>filterTasks(status)</code> function hides every task, then loops with <code>.each()</code>, reads the text inside <code>&lt;label class="status"&gt;</code>, and shows only the cards that match. No HTTP request needed &mdash; this is pure DOM logic with <code>.show()</code> and <code>.hide()</code>.</p>
</details>
