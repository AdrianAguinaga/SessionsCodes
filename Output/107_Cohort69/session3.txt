<h2 style="color: #0d2c4f; border-bottom: 3px solid #d23939; padding-bottom: 6px; font-size: 1.35rem;">🎯 Learning Outcomes</h2>
<div style="background-color: #ffffff; border-radius: 10px; padding: 20px 22px; margin-bottom: 24px; border: 1px solid #dde5ec;">
    <h3 style="color: #0d2c4f; margin-top: 0;">📖 Lesson Objective &amp; Concepts</h3>
    <p style="color: #1f2d3d; line-height: 1.6;">In almost every React application, we will need to retrieve data from various sources such as a <strong>backend server</strong>, a centralized store, or any form of in-memory persistence. Managing this data flow effectively is crucial for building dynamic and responsive user interfaces.</p>
    <p style="color: #1f2d3d; line-height: 1.6;">In this class, we will focus on consuming data&mdash;specifically, items for a store&mdash;from a <strong>mock service</strong>. This mock service initially provides data from a hardcoded array, simulating the retrieval of data without relying on an actual backend. This approach allows us to develop and test our frontend independently while the backend is still under development. Later on, we will enhance this service to fetch data from a real <strong>backend API</strong>, enabling our application to work with live data.</p>
    <p style="color: #1f2d3d; line-height: 1.6;">Using a mock service is a common practice in React development. It helps isolate the UI logic and data fetching concerns, making it easier to implement, debug, and maintain our applications. We will use React&rsquo;s <strong><code>useEffect</code></strong> hook to perform the data fetching operation when the component mounts, ensuring that the data is loaded efficiently and the UI updates accordingly.</p>
    <p style="color: #1f2d3d; line-height: 1.6; margin-bottom: 0;">As we progress, we will learn best practices for data fetching in React, including handling asynchronous requests, managing loading and error states, and optimizing performance. This foundation will prepare us to integrate more advanced data-fetching libraries, such as React Query, which improve scalability in real-world applications.</p>
</div>

        <ul style="color: #1f2d3d; padding-left: 20px; margin-bottom: 0;">
            <li style="margin-bottom: 12px;"><strong>Why is <code>useEffect</code> only called once with an empty dependency array?</strong><br /><span style="color: #5a6b7c;">An empty dependency array <code>[]</code> tells React that our effect does not depend on any props or state variables. Therefore, it only needs to run exactly once after the initial render (when the component mounts), which is perfect for fetching initial data.</span></li>
            <li style="margin-bottom: 12px;"><strong>What makes <code>filter()</code> powerful in React?</strong><br /><span style="color: #5a6b7c;">The <code>filter()</code> method allows us to create new arrays based on specific conditions without mutating the original state. This immutability is crucial in React for updating views dynamically, such as filtering products by category.</span></li>
            <li><strong>How does Bootstrap speed up layout design?</strong><br /><span style="color: #5a6b7c;">Bootstrap provides pre-built, responsive CSS classes and components. It allows us to quickly structure and style our UI without writing custom CSS from scratch, speeding up the development process significantly.</span></li>
