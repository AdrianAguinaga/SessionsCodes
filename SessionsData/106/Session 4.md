### Part 4.2: Event Delegation (The Logic)

The Problem: Students will try to write \$(\".btn-delete\").click(\...).
This will fail.

Why? Because when init() runs, those buttons don\'t exist yet! They are
created later when data loads.

Visual: Event Bubbling & Delegation

Use this text diagram to explain how we catch the click \"higher up\"
the tree.

> Plaintext

📡 EVENT DELEGATION VISUALIZED\
==============================\
\
Scenario: User clicks the trash icon on a NEW task.\
\
1. \[ Trash Icon \] \<\-- CLICK!\
│ \"Do I have a listener?\" NO.\
▼ (Bubbles Up)\
\
2. \[ Task Div \] \<\-- \"Do I have a listener?\" NO.\
│\
▼ (Bubbles Up)\
\
3. \[ #list Div \] \<\-- \"Do I have a listener?\" YES!\
│ We attached: \$(\".list\").on(\"click\", \...)\
│\
└── Logic: \"Was the actual target a \'.btn-delete\'?\
YES -\> Execute deleteTask()\"

Code to Share (scripts/app.js):

Update init to use the .on() syntax.

> JavaScript

function init() {\
console.log(\"App initialized\");\
\$(\"#btnSave\").click(saveTask);\
\
// OLD WAY (Doesn\'t work for dynamic items):\
// \$(\".btn-delete\").click(deleteTask);\
\
// NEW WAY (Event Delegation):\
// On click inside \".list\", if target is \".btn-delete\", run
deleteTask\
\$(\".list\").on(\"click\", \".btn-delete\", deleteTask);\
\
loadTasks();\
}

### Part 4.3: AJAX DELETE (The Implementation)

Now we implement the logic to remove the item from the server and the
screen.

**Code to Share (scripts/app.js):**

> JavaScript

function deleteTask() {\
console.log(\"Deleting task\...\");\
\
// 1. Context: \'this\' is the specific button that was clicked\
let btn = \$(this);\
\
// 2. Traversal: Find the parent div with the class \"task\"\
let taskElement = btn.parents(\".task\");\
\
// 3. Extraction: Get the unique ID we saved in the HTML earlier\
let id = taskElement.attr(\"id\");\
\
console.log(\"Requesting delete for ID:\", id);\
\
// 4. Server Communication\
\$.ajax({\
type: \"DELETE\",\
url: API + \"/\" + id, // Example URL: \.../api/tasks/12345\
success: function() {\
// 5. Success! Animate the removal from the screen\
taskElement.fadeOut(500, function() {\
\$(this).remove(); // Remove from DOM tree completely\
});\
},\
error: function(err) {\
console.error(\"Error deleting\", err);\
alert(\"Error deleting task\");\
}\
});\
}

Server Logic Review:

Remind students that the server code handles this by filtering the
array: DB = DB.filter(t =\> t.id !== id).

### Part 4.4: Client-Side Logic (Filtering)

Finally, we add a feature that doesn\'t need the server: showing/hiding
elements based on criteria.

Step 2: Logic (scripts/app.js)

We use jQuery\'s .toggle() or .hide()/.show().

> JavaScript

function filterTasks(status) {\
if(status === \'All\') {\
\$(\".task\").show();\
} else {\
\$(\".task\").hide(); // Hide everyone\
\
// Show only those that match.\
// We can look at the text inside the \<label class=\"status\"\>\
\$(\".task\").each(function(){\
let taskStatus = \$(this).find(\".status\").text();\
if(taskStatus === status) {\
\$(this).show();\
}\
});\
}\
}\
\
// Hook up in init()\
\$(\"#btnAll\").click(function(){ filterTasks(\'All\'); });\
\$(\"#btnDone\").click(function(){ filterTasks(\'Completed\'); });\
\$(\"#btnTodo\").click(function(){ filterTasks(\'New\'); }); // Assuming
\'New\' or \'In Progress\'
