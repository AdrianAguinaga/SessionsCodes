    <h3 style="color: #0d2c4f; margin-top: 0;">📖 Lesson Objective &amp; Concepts</h3>
    <p style="color: #1f2d3d; line-height: 1.6;">The goal of our lesson is to build a fully functional product catalog by leveraging <strong>reusable React components</strong>, passing data via <strong>props</strong>, and utilizing JavaScript array methods to handle data dynamically. We will introduce dynamic rendering of lists using the <code>map()</code> method combined with <strong>arrow functions</strong>, which allows us to efficiently generate UI elements from arrays of data.</p>
    <h4 style="color: #1b5a8a; margin-top: 24px; margin-bottom: 12px;">Introduction to Arrow Functions</h4>
    <p style="color: #1f2d3d; line-height: 1.6;"><strong>Arrow function expressions</strong> provide a concise and modern alternative to traditional function expressions in JavaScript. They simplify syntax, especially for inline functions used in React components, such as those passed to <code>map()</code>. However, arrow functions come with certain limitations compared to regular functions:</p>
    <ul style="color: #5a6b7c; padding-left: 20px; margin-bottom: 0;">
        <li style="margin-bottom: 8px;"><strong>No own <code>this</code> or <code>super</code> bindings:</strong> Arrow functions inherit <code>this</code> from their surrounding lexical context. They should not be used as object methods where a dynamic <code>this</code> is needed.</li>
        <li style="margin-bottom: 8px;"><strong>No <code>arguments</code> or <code>new.target</code>:</strong> Arrow functions do not have their own <code>arguments</code> object or <code>new.target</code> keyword, which limits their use in some scenarios.</li>
        <li style="margin-bottom: 8px;"><strong>Not suitable for <code>call()</code>, <code>apply()</code>, or <code>bind()</code>:</strong> Since arrow functions don&rsquo;t have their own <code>this</code>, these methods do not work as expected.</li>
        <li style="margin-bottom: 8px;"><strong>Cannot be used as constructors:</strong> Arrow functions cannot be used with the <code>new</code> keyword to create instances.</li>
    </ul>
    <p style="color: #1f2d3d; line-height: 1.6; margin-top: 12px; margin-bottom: 0;">Despite these restrictions, arrow functions are ideal for React&rsquo;s functional programming style, especially in rendering lists and handling events concisely!</p>

        <ul style="color: #1f2d3d; padding-left: 20px; margin-bottom: 0;">
            <li style="margin-bottom: 12px;"><strong>What is the role of props in component reuse?</strong><br /><span style="color: #5a6b7c;"><strong>Props</strong> allow components to receive dynamic data and configuration from their parent components. By passing different props, the same component can render varied content or behave differently, supporting modular and maintainable UI design.</span></li>
            <li style="margin-bottom: 12px;"><strong>How does <code>map()</code> improve scalability?</strong><br /><span style="color: #5a6b7c;">The <code>map()</code> method iterates over arrays and produces a component for each item. This scales effortlessly as data grows, keeping our code <strong>DRY</strong> (Don&rsquo;t Repeat Yourself) and easy to maintain.</span></li>
            <li><strong>Why does modular code matter in larger applications?</strong><br /><span style="color: #5a6b7c;">Modular code breaks down complex applications into manageable and reusable components. This improves maintainability by isolating functionality, facilitates collaboration, and accelerates development by reusing existing building blocks.</span></li>
        </ul>
