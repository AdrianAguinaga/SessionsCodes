<h2 style="color: #0d2c4f; border-bottom: 3px solid #d23939; padding-bottom: 6px; font-size: 1.35rem;">📚 What We'll Build Today</h2>
<p style="color: #1f2d3d; margin-bottom: 16px;">We are building a <strong>Task Manager</strong> web application. Click each part to expand the details.</p>
<details style="background-color: #ffffff; border-radius: 10px; padding: 14px 18px; margin-bottom: 10px; border: 1px solid #dde5ec;">
    <summary style="cursor: pointer; color: #0d2c4f; font-size: 1.05rem;"><strong>Part 1 &middot; Project Architecture</strong> &mdash; Separating concerns into folders</summary>
    <p style="margin: 12px 0 6px 0; color: #1f2d3d;">We move away from writing everything in a single file. Each piece of the app lives in its own place:</p>
    <pre style="background-color: #0d2c4f; color: #e8f0f8; border-radius: 8px; padding: 16px; font-size: 0.9rem; overflow-x: auto;">📁 TaskManager/               &lt;-- Root Folder
│
├── 📄 index.html             (The Skeleton: Structure)
│
├── 📁 style/                 (The Skin: Visuals)
│    └── 📄 app.css
│
└── 📁 scripts/               (The Brains: Logic &amp; Data)
     ├── 📄 task.js           &lt;-- Data Model (Class)
     └── 📄 app.js            &lt;-- Controller (Logic)</pre>
</details>
<details style="background-color: #ffffff; border-radius: 10px; padding: 14px 18px; margin-bottom: 10px; border: 1px solid #dde5ec;">
    <summary style="cursor: pointer; color: #0d2c4f; font-size: 1.05rem;"><strong>Part 2 &middot; The Skeleton (HTML) &amp; the DOM</strong> &mdash; Structure and element "hooks"</summary>
    <p style="margin: 12px 0 6px 0; color: #1f2d3d;">The browser reads our HTML and builds a tree of objects (the <strong>DOM</strong>). Key points:</p>
    <ul style="color: #1f2d3d; margin: 6px 0;">
        <li>The <code>&lt;link&gt;</code> to our CSS file goes in the <code>&lt;head&gt;</code>.</li>
        <li>The <code>&lt;script&gt;</code> tags go at the bottom of the <code>&lt;body&gt;</code> (jQuery first, then our scripts).</li>
        <li><code>id</code> attributes (e.g., <code>txtTitle</code>) act as hooks to grab elements later.</li>
    </ul>
</details>
<details style="background-color: #ffffff; border-radius: 10px; padding: 14px 18px; margin-bottom: 10px; border: 1px solid #dde5ec;">
    <summary style="cursor: pointer; color: #0d2c4f; font-size: 1.05rem;"><strong>Part 3 &middot; "Simple but Elegant" CSS</strong> &mdash; Cards, shadows, and CSS Grid</summary>
    <p style="margin: 12px 0 6px 0; color: #1f2d3d;">A modern Material-Design look without heavy libraries:</p>
    <ul style="color: #1f2d3d; margin: 6px 0;">
        <li><code>box-shadow</code> creates the 3D "lifting" effect of a physical card.</li>
        <li><code>repeat(auto-fit, minmax(200px, 1fr))</code> makes the form responsive on mobile with <em>zero</em> media queries.</li>
    </ul>
</details>
<details style="background-color: #ffffff; border-radius: 10px; padding: 14px 18px; margin-bottom: 10px; border: 1px solid #dde5ec;">
    <summary style="cursor: pointer; color: #0d2c4f; font-size: 1.05rem;"><strong>Part 4 &middot; The Data Model (DNA)</strong> &mdash; The <code>Task</code> class</summary>
    <p style="margin: 12px 0 6px 0; color: #1f2d3d;">Instead of passing loose variables around, we create a blueprint for what a "Task" looks like using a JavaScript <strong>class</strong> with title, description, color, date, status, and budget.</p>
</details>
<details style="background-color: #ffffff; border-radius: 10px; padding: 14px 18px; margin-bottom: 28px; border: 1px solid #dde5ec;">
    <summary style="cursor: pointer; color: #0d2c4f; font-size: 1.05rem;"><strong>Part 5 &middot; Initialization</strong> &mdash; <code>window.onload</code></summary>
    <p style="margin: 12px 0 6px 0; color: #1f2d3d;">We make sure our logic starts only when the browser is ready, using the <code>window.onload</code> event to call our <code>init()</code> function.</p>
</details>
