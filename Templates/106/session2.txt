    <p style="margin: 0 0 8px 0; color: #0d2c4f;"><strong>💡 Key Concept &mdash; Why client-side HTTP requests?</strong></p>
    <p style="margin: 0; color: #1f2d3d; font-size: 0.95rem;">Client-side HTTP requests let web applications talk to external servers <strong>without reloading the page</strong> &mdash; the foundation of dynamic, data-driven apps. JavaScript handles this with <strong>AJAX</strong> (Asynchronous JavaScript and XML) or the newer <code>fetch</code> API.</p>

<h2 style="color: #0d2c4f; border-bottom: 3px solid #d23939; padding-bottom: 6px; font-size: 1.35rem;">📚 What We'll Build Today</h2>
<p style="color: #1f2d3d; margin-bottom: 16px;">We breathe life into the Task Manager: the app will <strong>Read</strong> user input, <strong>Render</strong> visual elements, and <strong>Fetch</strong> data from the cloud. Click each part to expand the details.</p>
<details style="background-color: #ffffff; border-radius: 10px; padding: 14px 18px; margin-bottom: 10px; border: 1px solid #dde5ec;">
    <summary style="cursor: pointer; color: #0d2c4f; font-size: 1.05rem;"><strong>Part 1 &middot; Understanding the DOM</strong> &mdash; The tree we manipulate</summary>
    <p style="margin: 12px 0 6px 0; color: #1f2d3d;">The <strong>Document Object Model</strong> is a tree structure. When we write <code>$("#list")</code>, jQuery starts at <code>document</code> and hunts down the tree until it finds the unique ID. When we use <code>.append()</code>, we programmatically grow new "branches" (HTML elements) onto that part of the tree.</p>
    <pre style="background-color: #0d2c4f; color: #e8f0f8; border-radius: 8px; padding: 16px; font-size: 0.85rem; overflow-x: auto;">🌳 THE DOM TREE
      [ window ]
          │
     [ document ]
          │
      &lt;html&gt;
      /      \
  &lt;head&gt;    &lt;body&gt;
              │
    ┌─────────┼──────────────┐
 &lt;header&gt;   &lt;main&gt;        &lt;footer&gt;
              │
         &lt;section .card&gt;
              │
     ┌────────┴────────┐
  &lt;form&gt;            &lt;div id="list"&gt;  ◄── THE TARGET
     │                 ├── (We inject Task 1 here)
  &lt;input&gt;              └── (We inject Task 2 here)</pre>
</details>
<details style="background-color: #ffffff; border-radius: 10px; padding: 14px 18px; margin-bottom: 10px; border: 1px solid #dde5ec;">
    <summary style="cursor: pointer; color: #0d2c4f; font-size: 1.05rem;"><strong>Part 2 &middot; Capturing Data (Input)</strong> &mdash; <code>.val()</code> and the <code>saveTask()</code> function</summary>
    <p style="margin: 12px 0 6px 0; color: #1f2d3d;">When the user clicks "Save", we extract what they typed. The jQuery <code>.val()</code> method grabs the current text inside an input field. We then package those values into a <code>Task</code> object using the class we built in Session 1.</p>
</details>
<details style="background-color: #ffffff; border-radius: 10px; padding: 14px 18px; margin-bottom: 10px; border: 1px solid #dde5ec;">
    <summary style="cursor: pointer; color: #0d2c4f; font-size: 1.05rem;"><strong>Part 3 &middot; Rendering Data (Output)</strong> &mdash; Template literals &amp; "Local Echo"</summary>
    <p style="margin: 12px 0 6px 0; color: #1f2d3d;">We convert the JavaScript object back into HTML using <strong>Template Literals</strong> (backticks <code>``</code>) to mix HTML strings with variables <code>${var}</code> &mdash; including <strong>dynamic styling</strong> like <code>style="border-color:${task.color}"</code>. Fill out the form, click save, and watch the task appear instantly. This is called <strong>"Local Echo"</strong>.</p>
</details>
<details style="background-color: #ffffff; border-radius: 10px; padding: 14px 18px; margin-bottom: 10px; border: 1px solid #dde5ec;">
    <summary style="cursor: pointer; color: #0d2c4f; font-size: 1.05rem;"><strong>Part 4 &middot; Asynchronous Data (AJAX GET)</strong> &mdash; The "Waiter" metaphor</summary>
    <p style="margin: 12px 0 6px 0; color: #1f2d3d;">The local echo is temporary &mdash; refresh and it disappears. We need real data from the server. Think of AJAX as a <strong>waiter in a restaurant</strong>:</p>
    <ul style="color: #1f2d3d; margin: 6px 0;">
        <li><strong>Request:</strong> You (Client) tell the waiter (AJAX): "Get me the menu."</li>
        <li><strong>Async:</strong> While the waiter goes to the kitchen (Server), you sit at the table &mdash; you don't freeze.</li>
        <li><strong>Response:</strong> The waiter returns with the menu (JSON data).</li>
        <li><strong>Callback:</strong> You read the menu (<code>success</code> function).</li>
    </ul>
    <p style="margin: 12px 0 6px 0; color: #1f2d3d;">Example of the jQuery AJAX pattern we'll use:</p>
    <pre style="background-color: #0d2c4f; color: #e8f0f8; border-radius: 8px; padding: 16px; font-size: 0.85rem; overflow-x: auto;">$.ajax({
    type: "GET",      // HTTP Verb: READ
    url: API,         // Destination
    dataType: "json", // Expected format
    success: function(data) {
        console.log("Server responded with:", data);
    },
    error: function(err) {
        console.error("Error fetching data", err);
    }
});</pre>
</details>
<details style="background-color: #ffffff; border-radius: 10px; padding: 14px 18px; margin-bottom: 28px; border: 1px solid #dde5ec;">
    <summary style="cursor: pointer; color: #0d2c4f; font-size: 1.05rem;"><strong>Part 5 &middot; Wiring It Up</strong> &mdash; Hooking the button &amp; loading on start</summary>
    <p style="margin: 12px 0 6px 0; color: #1f2d3d;">We update <code>init()</code> to hook up the Save button with <code>$("#btnSave").click(saveTask)</code> and call <code>loadTasks()</code> so data loads from the server the moment the app starts.</p>
</details>
